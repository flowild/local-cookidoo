Dein Rezeptgarten als App

Öffne diese Seite in Chrome auf deinem Handy. Wähle im Drei-Punkte-Menü „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Lokales HTTPS einrichten

Falls Chrome eine Zertifikatswarnung zeigt: Lade das lokale CA-Zertifikat herunter und installiere es über die Zertifikatseinstellungen deines Geräts. Öffne danach diese HTTPS-Adresse erneut. Vertraue dem Zertifikat nur, wenn es von deinem eigenen Server stammt.

CA-Zertifikat herunterladen

Die App verbindet sich mit deinem Server im Heimnetz. Ohne Verbindung zum Server können keine Rezeptlisten geladen werden.
