# Rezeptgarten für Android

Die native Flutter-App für Rezeptgarten heißt im Android-Startmenü **Rezeptmix**.
Im Heimnetz verbindet sie sich direkt mit dem Server. Unterwegs nutzt sie die
im Heimnetz eingerichtete Telegram-Verbindung.
